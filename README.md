# Character_Image_Classification
# จำแนกภาพตัวละคร Zenless Zone Zero ด้วย AlexNet

โปรเจกต์ Machine Learning ประเภท Classification สำหรับจำแนกภาพตัวละครจากเกม Zenless Zone Zero จำนวน 10 ตัว ใช้โมเดล AlexNet (PyTorch) ที่ผ่านการฝึกกับ ImageNet มาแล้ว แล้วปรับให้เข้ากับตัวละครในโปรเจกต์ เขียนและรันบน Google Colab

โปรเจกต์นี้ทำขึ้นเพื่อการเรียนรู้ ไม่เกี่ยวข้องกับเจ้าของเกมแต่อย่างใด

## ตัวละครที่ใช้

Bella, Burnice, Ellen, Grace, JaneDoe, King Caesar, Miyabi, Nicole, Wise, Yanagi

## ข้อมูลและการแบ่งข้อมูล

- ตัวละครละประมาณ 100 รูป ใช้ชื่อโฟลเดอร์เป็น Label
- แบ่งข้อมูลด้วย Scikit-learn แบบรักษาสัดส่วนคลาส (stratified)

| ชุดข้อมูล | สัดส่วน | ใช้ทำอะไร |
|---|---|---|
| ฝึก (Train) | 70% | สอนโมเดล |
| ตรวจสอบ (Validation) | 15% | ให้ Early Stopping และการลด learning rate ดูผล |
| ทดสอบ (Test) | 15% | วัดผลสุดท้ายครั้งเดียว |

## วิธีการ

- โมเดล: AlexNet จาก torchvision (น้ำหนัก ImageNet) เปลี่ยนชั้นสุดท้ายให้ตรงกับจำนวนคลาส
- Augmentation (เฉพาะชุดฝึก): กลับซ้ายขวา, หมุน ±15 องศา, ปรับความสว่าง ความคมชัด และความอิ่มสี
- การเทรน: Adam, learning rate 0.0001, batch 32, สูงสุด 25 รอบ, ขนาดรูป 224×224
- ป้องกัน Overfit:
  - Early Stopping (หยุดเมื่อ validation loss ไม่ดีขึ้น 5 รอบ แล้วย้อนไปใช้น้ำหนักรอบที่ดีที่สุด)
  - ลด learning rate อัตโนมัติ (ลดครึ่งหนึ่งเมื่อ validation loss ไม่ดีขึ้น 3 รอบ)
- การวัดผล: Accuracy, Precision, Recall, F1 และ Confusion Matrix

## ผลลัพธ์

วัดจากชุดทดสอบที่แบ่งมาจากกองข้อมูลเดียวกับชุดฝึก

| การทดลอง | จำนวนรูปทดสอบ | Accuracy | Precision (macro) | Recall (macro) | F1 (macro) |
|---|---|---|---|---|---|
| 10 คลาส | 150 | 0.953 | 0.954 | 0.953 | 0.953 |
| 11 คลาส (เพิ่มคลาส Other) | 165 | 0.879 | 0.885 | 0.879 | 0.880 |

การทดลองที่ 2 เพิ่มคลาส "Other" (รูปตัวละครอื่นนอกกลุ่ม 100 รูป) เพื่อให้โมเดลแยกรูปนอกกลุ่มได้ ผลคือ Accuracy รวมลดลง และคลาส Other เองได้ Precision 0.471, Recall 0.533

## ข้อจำกัดที่พบ

- โมเดล 10 คลาสไม่มีคำตอบว่า "ไม่ใช่ตัวละครใดเลย" ถ้าอัปโหลดรูปตัวละครนอกกลุ่ม โมเดลจะทายเป็นหนึ่งใน 10 ตัวด้วยความมั่นใจสูง (ตัวอย่างที่ทดสอบ: 96.3%)
- ค่าความมั่นใจที่แสดงคือความมั่นใจของโมเดลต่อรูปนั้น ไม่ใช่ความแม่นยำรวม และอาจสูงเกินจริงได้
- ชุดทดสอบมาจากกองข้อมูลเดียวกับชุดฝึก ผลกับรูปใหม่จากอินเทอร์เน็ตจึงอาจแย่กว่าตัวเลขข้างต้น
- ชุดทดสอบมีเพียง 15 รูปต่อคลาส ตัวเลขรายคลาสจึงแกว่งง่าย

## วิธีใช้งาน

1. เตรียมโฟลเดอร์รูปตามโครงสร้างนี้ (ไม่ได้รวมรูปไว้ใน repository นี้)

```
โฟลเดอร์หลัก/
├── Bella/
├── Burnice/
├── Ellen/
└── ... (ชื่อโฟลเดอร์ = ชื่อตัวละคร)
```

2. เปิดไฟล์ `zzz_classifier.ipynb` ใน Google Colab
3. เปิดใช้ GPU ที่ Runtime → Change runtime type → GPU
4. แก้ตัวแปร `DATA_DIR` ในช่องแรกให้ชี้ไปยังโฟลเดอร์รูปของคุณ
5. รันทีละช่องตามลำดับ ช่องสุดท้ายใช้โหลดโมเดลที่บันทึกไว้และลองอัปโหลดรูปเพื่อทายตัวละคร
